# Surface: atmosfx landing page (docs/index.html)

Mode: Persuade. Audience: web developers first; non-coders / vibe coders second (agent prompt). Action: copy the install line or the agent prompt after picking an effect. Proof: the effects themselves, running live from the published package; measured sizes from scripts/size.mjs. Constraints: static HTML on GitHub Pages, CDN-loaded package, honor reduced motion, no invented stats. Replaces the brick "night street facade" world (user asked for a full redesign on 2026-11-22: hero felt cheap, effects barely visible, lower half boring).

## Direction contract

THESIS: every effect is a destination on a station departures board; each row is a full-width live strip of that weather, and boarding a row pours it over the page. Refuses the centred headline over one background canvas, and refuses small thumbnail tiles.

OWN-WORLD: board-housing black ground owns the whole page, split-flap tiles (dark tile, hairline split, off-white glyph) for names and measured numbers, station yellow only for selected / primary / links / focus, signal green only for live status. Barlow Condensed for board and headings, Atkinson Hyperlegible Next for prose, JetBrains Mono for code. The install and code are a printed boarding pass with a perforated stub.

STORY: the visitor sees ten wide rows of real weather, reads "Weather for any element", boards one (row flips to NOW BOARDING, weather covers the page, pass code rewrites), tunes it with detented controls and live flap readouts, then copies install + code, or the agent prompt.

FIRST VIEWPORT: yellow station sign strip (mark + nav); the board: DEPARTURES flap header with live clock, h1 hook and sub on the left of the message line with the boarding pass (install + current mount line, each with Copy) on the right; then ten rows (SEASON, EFFECT in flaps, open weather strip, REMARKS, STATUS). On phones rows keep season/effect/status, pass stacks under the hook.

FORM: assigned grounded direction, candidate 7 of 7 (Departures Board), seed:0584961bfea26a41. Raises: still type over drifting weather (cracktro), detented controls + live instruments (oscilloscope), edge-to-edge rows with no card gutters (doujin catalog). Signature interaction: boarding a row flips its flaps to NOW BOARDING and pours the weather over the page; winter caps the board's flap header with snow via settleOn. Motion grammar: weather is the motion; UI only moves as a flap flip when the board changes.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
