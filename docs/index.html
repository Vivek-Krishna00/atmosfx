What's in the building

      

        
6.7 kBcore + one effect, gzipped
The engine alone is 6.1 kB and one effect brings it to 6.7 kB. All ten effects together are about 13.5 kB. Measured with esbuild and gzip level 9, no dependencies.

        
60 fpson a CPU slowed 6×
The full winter scene held 60 fps in Chrome with the CPU throttled six times. Quality steps down on its own after about a second of slow frames, and back up when there is headroom.

        
Page or element
Effects.mount('page', …) covers the viewport; pass an element or a CSS selector to keep the weather inside one box. Every window above is its own mount.

        
Polite by default
Pauses in background tabs, honors prefers-reduced-motion with a still frame, never blocks clicks, and returns a do-nothing handle on the server, so it is safe in SSR frameworks.

        
Seasons
Effects.auto() picks the effect for the current month: winter, cherry blossom, summer, autumn. Override any month, or flip it for the southern hemisphere.

        
Your own
registerEffect() takes plain data plus one draw function. Sprites are drawn once ahead of time, never per frame.

The whole API

      

        

          
const fx = Effects.mount(target, effect, options);
// target: 'page' | Element | CSS selector

fx.update({ intensity: 1 });
fx.switch('rain');
fx.pause(); fx.resume();
fx.stats();   // { fps, particles, quality, … }
fx.destroy();

Effects.auto('page', options, { hemisphere: 'south' });

// smallest bundle: no names registered
import { Effects, snow } from '@vivekkrishna30/atmosfx/core';
Effects.mount('page', snow);

        

        

          
Options

          

            
intensity0 to 1, particle count. Default 0.5

            
speed · sizeMultipliers. Default 1

            
wind-1 to 1, sideways push

            
colorsReplace the palette, up to 5

            
opacity · zIndexHow the canvas sits on the page

            
quality · fps'auto' adapts; fps caps the frame rate

            
interactiveParticles part around the cursor

            
ground · settleOnWinter's snow bank, and elements to cap

          

          
Full reference and custom effects: README on GitHub.
